# Meshy style guide (DON'T WAKE THE BRAINROT)

Shared style suffix for every prompt:
"chunky vinyl toy figure, smooth rounded simple shapes, clean flat saturated colors, minimal surface detail, big readable facial features, cute cartoon, single character, full body, front three-quarter view, plain white background, soft studio light"

Mesh rules: one closed mesh, ~3-5k triangles, pivot bottom-centre, faces +Z after import.
